# Lightweight Feature Selection for IDK Cascade Skip Decisions

A two-feature logistic regression matches a Random Forest skip predictor for
real-time IDK cascades — at a **measured 84× lower per-decision cost** (median
33 µs vs. 2.80 ms, batch size 1, x86 CPU).

**[Read the paper (PDF)](paper/final_paper.pdf)** — IEEE 2-column,
RTSS Work-in-Progress style.

## What this is

*IDK cascades* (Wang et al., 2017) chain classifiers of increasing accuracy and
cost — here ResNet-18 → ResNet-34 → ResNet-152 — where each stage either
commits to a prediction or says "I don't know" and defers to the next. Two
recent RTSS Work-in-Progress papers speed this up by *skipping* the middle
classifier when it is unlikely to help:

- **Nguyen, Cheng & Carroll (RTSS 2024)** skip when the first stage's
  confidence falls below a static 0.3 threshold.
- **Katikaneni, Cheng & Carroll (RTSS 2025)** replace the threshold with a
  Random Forest on three softmax features (confidence, entropy, margin),
  trained to predict whether the middle classifier will abstain.

This project asks the question Katikaneni et al. left as future work: **does a
much simpler predictor suffice?** In a real-time setting the skip predictor's
own WCET is charged against the schedulability budget, so predictor cost is a
first-class concern, not an implementation detail.

## Headline results

10,000-image ImageNet-V2 Matched-Frequency set; learned predictors trained on
the will-B-abstain label of Katikaneni et al.; cascade metrics on the held-out
30% test split of the 4,857 images where the first stage abstains (the only
population where the skip rule is consulted).

| Variant | Latency (ms/img) | Top-1 Acc | Skip-F1 | Per-decision cost |
|---|---|---|---|---|
| Baseline (no skip) | 137.21 | 0.464 | — | — |
| Static τ=0.3 (Nguyen 2024) | 130.44 | 0.467 | — | ~0 |
| Random Forest (Katikaneni 2025, re-impl.) | 129.45 | 0.469 | 0.715 | 2.80 ms |
| **Logistic, 2 features (this work)** | 129.47 | 0.470 | 0.706 | **33 µs** |

The trained rule is fully interpretable:

```
logit P(skip) = 1.787 − 5.111·conf + 1.086·margin
```

The logistic does not dominate the Random Forest — it concedes 0.009 absolute
skip-F1 — but it delivers the same cascade latency and accuracy while its
evaluation cost (two multiplies, two adds, one sigmoid) is a floor no 50-tree
ensemble reaches. The reported cascade latencies *exclude* predictor cost;
charging each variant its own median per-decision cost adds 2.80 ms to the
Random Forest row and 0.03 ms to the logistic row.

## Repository layout

```
paper/     LaTeX source + compiled PDF (IEEEtran vendored; tables are
           auto-generated by the code — never hand-edited)
code/      analysis pipeline (see code/README.md)
data/      cached softmax outputs, per-image CPU timings, labels (~116 MB,
           committed so the analysis reproduces in minutes without the
           ~2-hour model-inference step)
figures/   generated plots
```

## Reproduce

```bash
pip install -r code/requirements.txt
cd code
python3 threshold_sweep.py   # sweep table + figure (seconds)
python3 skip_rule.py         # trains RF + logistic, all result tables (seconds)
```

Regenerating `data/` from scratch (`cache_softmax.py`, ~2 h CPU) is only needed
if you want fresh timings; note the caveat in that file's loader about
ImageNet-V2 variant naming on Hugging Face.

## Limitations

This is work-in-progress-scale research, honestly labeled as such: one
ImageNet-V2 subset (Matched-Frequency), single-dataset 70/30 evaluation
(vs. Katikaneni et al.'s cross-dataset protocol), x86 CPU rather than embedded
ARM, and a scikit-learn Random Forest as the cost baseline (a compiled ensemble
would narrow — not close — the 84× gap).
